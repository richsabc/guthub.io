 上周末没事干，折腾了个全免费静态网站，这两天硬塞一点料上去。工具包括 GitHub账户、安装GitHub Desktop、Obsidian、Gitbash(可有可无)。还有，像我一样老小白，AI协助调试少不了。为了实现个别自动功能，绝对没有网上介绍的那么简单，没AI协助我估计无法实现，或者要折腾比较久。我的实现方式与工具可能是最简单易学的，碰上麻烦无脑问AI。过程也发现AI实际上还不是那么有智慧，它会带你走弯路，你必须先知道一点方向并及时提醒它。）。建站动机：全免费、没事找事、相对稳定。优势：1、Github可预期相对长时间存在。大概二十年前在一些论坛写的博客、贴的一些照片，早就因为网站各种原因消失或者无法完整显示了。而且，发的东西不属于你自己的，大部分无法备份到本地。2、发照片可以比微信等其他平台更高清，清晰度自己控制。
 如果不为了某些便利需求，并无计划经常更新，可以比网上说的简单性更简单，只用 GitHub 网页端就可完成网站搭建、写作和发布，不需要 GitHub Desktop、Obsidian，Git bash等工具。当然，过程也就没那么好玩。
    网站无毒、无访问跟踪功能，放心点击，链接在本文头尾。[微笑]
